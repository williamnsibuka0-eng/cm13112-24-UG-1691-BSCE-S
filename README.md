# Assignment A2 — Proof of Life

### Program Description
This Python program loads and analyzes the provided data from the CSV file using a Jupyter Notebook.

### File List
* `cml3112-yourstudentnumber.ipynb` - Core Jupyter notebook containing the code.

### Run Instructions
1. Open this notebook in Google Colab.
2. Ensure the supplied CSV file is uploaded to the Colab environment.
3. Select 'Runtime' > 'Restart and run all' from the top menu.

The engineering problem is to automate data validation and processing from an external CSV file to ensure reliable software output.
